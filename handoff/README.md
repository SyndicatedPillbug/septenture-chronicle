# Septenture Chronicle — handoff files

One file per chapter, generated from the live site by `scripts/export-handoff.py`.
Hand these to an editing agent; return them with the same filenames and the site can be updated from them.

## What to edit

Only the prose. Keep:

- the `# Title` line
- the `<!-- source: ... -->` comment at the top
- the `*dateline*` line (the in-world date; keep its wording)
- the closing italic line on chapters that have one (`*Next: ...*`)
- `<p class="turnmark">✦</p>` markers in dream/interlude chapters (they separate turns)

Everything else is fair game: reorder, cut, rephrase, sharpen.

## House style

- Mirror antithesis is banned as a reflex, in all six disguises: "not X but Y"; the sentence-pair
  version ("That does not excuse the errors. It means they are workable."); the reversed form
  ("Y, not X"); the anaphoric mirror ("The question is never X. The question is Y."); preposition
  skins ("rather than", "instead of", "no X, only Y"); double-negative parallels. State the positive
  claim and let it stand.
- Limit passive "to be" constructions. Prefer a person doing the verb.
- No superficial "-ing" tails, no copula avoidance ("serves as", "stands as"), no significance
  inflation, no vague attribution, no synonym-cycling, no noun pileups.
- AI-tell budgets: one rule-of-three run per chapter (and the third item should turn); no anaphora
  runs ("Somebody X. Somebody Y. Somebody Z."); two polished aphorisms per piece at most; one
  metaphor per beat; no stock personifications ("the sea breathed and did not care"); avoid "the way
  X is X" similes; vary sentence length hard; give specifics (numbers, prices, times); spend
  em-dashes sparingly; leave a thread loose.
- Voice: long cumulative sentences mixed with blunt short ones; concrete nouns; cold stone and warm
  lamplight; speech that comes from where the speaker stands. Third person past for Chronicle
  chapters, second person for dream and interlude prose.
- Keep in-world facts exactly as stated (names, dates, places). If a fact looks wrong, flag it in a
  comment rather than changing it silently.
