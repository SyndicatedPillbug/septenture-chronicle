# Septenture site maintenance

For played-session updates, begin with `maintenance/README.md` and `maintenance/surfaces.json`. Keep a per-session review record and run `npm run audit:session` before publishing. Reset human browser checks for each release and verify the actual interface; passing source checks is not proof that a feature works.

Keep GM prep, future reveals, private sheets and notebooks out of public content. Preserve player-authored live profiles. `handoff/` is generated editorial material rather than the authoritative published source. Add any new session-sensitive surface to the central catalog.
